# DSA Assignment 2 — C Programs

Beginner-friendly C implementations based on the programming/algorithm questions in Assignment 2 (Arrays, Stacks and Queues).

## Folders
- `Array/` — array insertion/deletion/search/reversal/rotation and common array problems.
- `Stack/` — stack operations, expression conversion/evaluation, parentheses and stack algorithms.
- `Queue/` — queue/circular queue/deque operations and common queue problems.

## Compile and run
Using GCC:
```bash
gcc filename.c -o program
./program
```
On Windows:
```bash
gcc filename.c -o program.exe
program.exe
```

Each `.c` file is a separate program. Most programs use fixed example data to keep the algorithm easy to understand; edit the sample values to test other cases. These are educational implementations, not production libraries.
